## 🚀 Aplicação Online

Você pode acessar a aplicação rodando ao vivo através deste link: [Coffee Shop](https://coffee-shop-pihu.vercel.app/)

## 🛠️ Tecnologias Utilizadas
-   **React**: Biblioteca JavaScript para construção de interfaces de usuário.
-   **React Router**: Biblioteca para gerenciar navegação e rotas em aplicações React.
-   **Axios**: Biblioteca para fazer requisições HTTP.
-   **React Hook Form**: Biblioteca para gerenciamento de formulários em React.
-   **React Query**: Biblioteca para gerenciamento de estado assíncrono e cache de dados.
-   **Tailwind CSS**: Framework de CSS utilitário para estilização rápida e customizável.
-   **React Toastify**: Biblioteca para exibição de notificações.

## ⚙️ Funcionalidades

-   **Página de produtos**: Visualize uma lista de produtos disponíveis na loja.
-   **Carrinho de compras**: Adicione e remova itens do carrinho de compras.
-   **Checkout**: Finalize sua compra através de um processo de checkout simples.
-   **Design responsivo**: Experiência otimizada para dispositivos móveis e desktops.

## 🚧 Instalação e Uso Local

Para rodar o projeto localmente, siga as instruções abaixo:

1.  Clone o repositório:



Copiar código

`git clone https://github.com/RafaelFigueiredo2203/coffee_shop.git` 

2.  Navegue até o diretório do projeto:



Copiar código

`cd coffee_shop` 

3.  Instale as dependências:



Copiar código

`npm install` 

4.  Inicie o servidor de desenvolvimento:


Copiar código

`npm run dev` 

5.  Acesse a aplicação em `http://localhost:3000`.
